# MATRXe - منصة التوائم الرقمية الذكية

منصة الذكاء الاصطناعي الرائدة لإنشاء التوائم الرقمية الذكية. أنشئ توأمك الرقمي الذي يحاكي صوتك وملامحك ويساعدك في مهامك اليومية.

## التقنيات المستخدمة

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase
- Three.js

## التشغيل المحلي

```sh
npm install
npm run dev
```

## النشر

راجع `DEPLOY-GUIDE.md` لتعليمات النشر الكاملة على VPS + Supabase.
